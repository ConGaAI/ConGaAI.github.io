## What this document is for

AI Forge is a desktop window. It connects this computer to the channel, launches assistants, and can store local files in a searchable library.

Connection, authorization, and assistant install all happen in the app. These pages match the screens and screenshots. Follow the window.

## Terms

| Term | Meaning |
|---|---|
| **Channel** | The private connection from this computer to the service. Conversation and document understanding both use it. |
| **Authorization key** | Proves **this computer** may use the channel. Created under Connection → Authorize. Use **Copy key** and send the full line to an admin. |
| **Service key** | Proves **you** may use conversation and document understanding. Issued by an admin. Paste it only on Connection. |
| **Conversation** | Questions, answers, writing code. |
| **Document understanding** | Turns files into searchable meaning, not just keyword match. |
| **Local store** | A private database on **this computer** for imported files. |
| **Dataset** | A named box, e.g. “product docs”. Pick one when you import. |
| **Agent** | The assistant that edits your project. It opens in a **new window** in the folder you chose. |
| **Recent projects** | At most 10 shortcuts. Click to launch. They do not show in-progress work and do not close that window. |

Do not mix the two keys. Always use **Copy key**; do not select the shortened line on screen.

## Four steps are enough the first time

1. Save the username. Copy the authorization key to an admin.
2. After connect succeeds, paste and verify the service key.
3. (Recommended) Install the local store.
4. Pick an agent, add a project folder, click to launch.
