# Status

Public guide: [GitHub · Status](https://github.com/ConGaAI/AI-Forge/blob/main/docs/en/status.md)

![Status](/assets/ai-forge/status.png)

This screen answers one question: **can you start working now?**

## Suggested next step

The banner at the top names the next action: connect, verify the key, install the local store, or launch an agent. Click it to jump.

## Readiness

All four items on means this computer is ready for the full set of features:

| Item | Meaning | If not ready |
|---|---|---|
| Channel | Connected | [Connection](/docs/AI-Forge/Connection) |
| Conversation | Service key works for Q&A and code | [Connection](/docs/AI-Forge/Connection) |
| Document understanding | Files can become searchable meaning | [Connection](/docs/AI-Forge/Connection) |
| Store | Local store is ready | [Data setup](/docs/AI-Forge/Data) |

Each item is also a shortcut.

## Health checks

The three cards below are live checks: remote entry, local channel, local store. After a connect or install, click **Recheck**.

The top bar also shows channel and store badges on every screen.
