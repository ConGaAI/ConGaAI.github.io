# Agents

Public guide: [GitHub · Agents](https://github.com/ConGaAI/AI-Forge/blob/main/docs/en/agents.md)

![Agents](/assets/ai-forge/agents.png)

Install assistants here and launch from recent project folders. The list holds at most 10 shortcuts: click a folder name to open a new window. It does not show in-progress work and does not close that window.

If you are not connected, the page asks you to finish [Connection](/docs/AI-Forge/Connection) first.

## Pick an assistant

| Assistant | What it is for |
|---|---|
| OpenCode | General coding assistant |
| Codex | Writing and editing code |
| Grok Build | Another coding assistant |
| Claude Code | Edits the project in a conversation |

If the card says not installed, install before launch. Prefer **One-click install** in the window.

## Install

1. Select a card.
2. If supported, click **One-click install** and wait.
3. Or **Open install docs** for the official steps.
4. Then **I installed it, recheck**.

If it asks for Node.js, install Node.js 22 or newer, reopen AI Forge, and try again. Some assistants need you to quit AI Forge and open it again after install.

## Recent projects

1. Click **Add folder** and pick a local project.
2. **Click the folder name** to launch the selected assistant in that directory.
3. **Launch** on the right starts the folder marked active.
4. The trash can only removes the shortcut. It does not delete files on disk.

You can search folder names above the list.
